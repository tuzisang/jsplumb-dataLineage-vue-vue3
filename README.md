# 数据血缘关系可视化工具

这是一个基于 Vue.js 和 Python Flask 开发的数据血缘关系可视化工具。

## 项目介绍

本项目旨在帮助用户直观地展示和分析数据之间的血缘关系。通过可视化的方式，用户可以清晰地了解数据流转过程和依赖关系。

### 技术栈

#### 前端
- Vue 3
- JSPlumb：用于绘制流程图和连接线
- TypeScript
- Vite 4

#### 后端
- Python Flask
- SQLLineage：用于SQL解析和血缘关系分析
- NetworkX：用于图形数据结构处理

### 主要功能
- **关键血缘图**：智能识别和展示核心业务数据的关键链路
- 数据表血缘关系可视化（列级和表级）
- 拖拽式节点布局
- SQL自动解析生成血缘关系
- 智能搜索定位（表名/列名）
- 上下游链路高亮追踪
- 关键路径聚焦模式

## 本地开发环境搭建

如果您想在本地进行开发，需要以下环境：

## 功能详细说明

### 关键血缘图功能

#### 功能概述
- **智能识别**：自动识别核心业务数据的关键链路
- **一键切换**：支持全景图与关键血缘图的快速切换
- **布局统一**：初始加载与切换模式保持一致的坐标计算
- **聚焦分析**：突出显示影响业务的核心数据流转路径

#### 核心特性
- **自动计算**：基于节点重要性智能计算关键路径
- **视觉统一**：避免切换时的视觉跳变，提升用户体验
- **高效分析**：快速定位核心业务数据的上下游关系
- **动态调整**：支持手动调整关键节点并实时更新

### 数据血缘关系可视化

#### 功能概述
- 列级和表级血缘关系可视化
- SQL自动解析生成血缘关系
- 智能搜索定位
- 上下游链路高亮追踪

#### 核心特性
- 拖拽式节点布局
- 智能搜索定位
- 链路高亮显示

### 小地图功能

#### 功能概述
- 提供全局视图导航，帮助用户快速定位和浏览大型血缘图
- 通过缩略图展示所有节点和连接关系的概览
- 支持多种交互方式：拖拽视口指示器、点击小地图区域、缩放控制

#### 核心特性
- **视口指示器**：实时反映主画布的可视区域，支持拖拽移动
- **点击导航**：点击小地图任意位置，主画布自动定位到对应区域
- **缩放控制**：提供放大、缩小和重置按钮，方便调整小地图视图
- **自适应缩放**：根据画布内容自动计算合适的初始缩放比例
- **本地存储**：保存用户自定义的缩放比例设置

#### 交互方式
- **视口拖拽**：在小地图上拖拽视口指示器框，主画布会同步移动
- **地图点击**：点击小地图空白区域，主画布会定位到点击位置
- **缩放操作**：使用控制按钮调整小地图的缩放级别

#### 使用技巧
- 当血缘图较大难以导航时，使用小地图快速定位目标区域
- 通过拖拽视口指示器精确控制主画布的可视区域
- 使用缩放功能在概览和细节视图之间切换
- 小地图会自动保存最后一次使用的缩放比例

#### 注意事项
- 小地图仅在有节点数据时显示
- 视口指示器的位置和大小会根据主画布的缩放和位置实时更新

### 表类型过滤与分组功能

#### 功能概述
- 表类型筛选（Origin、Middle、RS）
- 智能分组展示
- 颜色标识系统

#### 核心特性
- **多选筛选**：实时反映筛选结果
- **智能分组**：按类型自动分组，显示数量统计
- **状态保持**：筛选状态跨模式保持

## 开发说明

- 本项目使用 Vue 3 + TypeScript 开发
- 使用 JSPlumb 实现节点之间的连接和交互
- 后端基于 SQLLineage 进行二次开发，实现 SQL 解析和血缘分析
- 支持自定义节点样式和连接线样式
- 提供完整的 API 接口文档
