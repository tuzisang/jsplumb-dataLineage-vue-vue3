# 数据血缘关系可视化工具 - 前端增强版

> **🎯 基于原生开源项目的前端深度定制**
>
> 本项目针对 [jsplumb-dataLineage-vue](https://github.com/mizuhokaga/jsplumb-dataLineage-vue) 前端进行深度二次开发，构建了完整的企业级数据血缘可视化解决方案。
> 后端解析SQL[SQLLineage](https://github.com/reata/sqllineage/actions)，没有过多改造，直接调用SQLLineage的API，解析SQL，返回血缘关系。

## 📊 项目概述

这是一个专为数据分析师和数据工程师设计的智能化数据血缘关系可视化工具。通过深度定制前端界面，我们实现了从基础展示到专业级分析的跨越式升级，为用户提供前所未有的数据血缘分析体验。

### 🎯 二次开发核心动因

#### 原前端项目局限性
经过深入分析，原前端项目存在以下关键局限：

1. **功能单一**：仅支持基础的血缘关系展示，缺乏交互式分析能力
2. **体验粗糙**：缺乏现代化的用户界面和交互设计
3. **性能瓶颈**：大数据量场景下界面卡顿，缺乏优化
4. **扩展困难**：组件化程度低，难以支持复杂业务需求

#### 前端创新价值定位
基于实际业务需求，我们确立了三大核心创新方向：
- **交互革命**：构建完整的前端交互体系
- **视觉升级**：打造现代化的数据可视化界面
- **体验优化**：实现企业级的用户操作体验

## 🚀 技术架构（前端专精）

### 前端技术栈（深度优化）
- **Vue 3.4+** + **TypeScript 5.0+**：现代化开发框架，类型安全
- **JSPlumb 6.0+**：专业的图形连接库，深度定制版本
- **Vite 5.0+**：极速构建工具，开发体验优化
- **原生JavaScript**：高性能算法实现，无额外依赖
- **CSS Grid + Flexbox**：响应式布局，完美适配

### 后端技术栈（保持原生）
- **Python Flask**：轻量级Web服务
- **SQLLineage**：SQL血缘解析核心（未修改）
- **NetworkX**：图数据结构处理（未修改）

## ✨ 前端核心创新亮点

### 1. 🎯 双模式血缘分析
#### 表级血缘模式
- **完整表关系**：展示表与表之间的完整血缘链路
- **表类型识别**：智能识别源表、中间表、结果表
- **批量操作**：支持多表同时选择和操作

#### 列级血缘模式
- **精确到字段**：展示字段级别的详细血缘关系
- **字段追踪**：支持单个字段的上下游追踪
- **智能分组**：按表类型自动分组显示字段

### 2. 🔍 智能搜索与定位系统
#### 多维度模糊搜索
- **实时搜索**：输入即搜索，毫秒级响应
- **智能匹配**：支持表名、字段名的模糊匹配
- **高亮显示**：搜索结果实时高亮标记
- **搜索历史**：自动保存搜索记录

#### 镜头定位功能
- **精准定位**：一键定位到任意表或字段
- **批量导航**：支持按顺序批量查看关键节点
- **视口动画**：平滑的视角切换动画
- **记忆功能**：记住上次查看位置

### 3. 🎨 现代化交互界面
#### 可折叠面板设计
- **SQL面板**：支持最小化，释放画布空间
- **节点列表面板**：可拖拽调整宽度，分组显示
- **历史记录面板**：折叠式设计，快速访问

#### 智能图例系统
- **表类型图例**：颜色编码的表类型说明
- **动态图例**：根据实际数据自动生成
- **交互式图例**：点击图例可快速筛选

### 4. ⚡ 性能优化创新
#### 虚拟化渲染
- **节点懒加载**：仅渲染可视区域节点
- **智能缓存**：缓存计算结果，避免重复渲染
- **批量处理**：支持大数据量的分批加载

#### 响应式优化
- **防抖处理**：搜索输入防抖，减少计算频率
- **节流渲染**：拖拽操作节流，提升流畅度
- **内存管理**：自动清理无用数据，防止内存泄漏

### 5. 📊 关键血缘分析
#### 智能路径识别
- **关键路径计算**：基于节点重要性自动计算关键血缘
- **一键切换**：全景图与关键血缘图无缝切换
- **动态调整**：支持手动选择关键节点，实时更新

#### 可视化增强
- **链路高亮**：关键路径高亮显示
- **节点聚焦**：聚焦模式下的节点突出显示
- **关系简化**：隐藏非关键节点，突出核心关系

## 🚀 快速开始

### 环境要求
- **Node.js**: 22.11.0 或更高版本
- **Python**: 3.12.9 或更高版本（用于后端API）
- **npm**: 10+ 或更高版本

### 开发环境启动
```bash
# 克隆项目
git clone <仓库地址>
cd jsplumb-dataLineage-vue-vue3

# 前端启动
npm install
npm run dev
# 访问: http://localhost:8620

# 后端启动（保持原生）
cd api
pip install -r requirements.txt
python server.py
# API地址: http://localhost:5000
```
